========================================
Aim Lab 练枪模拟器 - 快速使用指南
========================================

欢迎使用 Aim Lab 练枪模拟器！本指南将帮助你快速上手。

========================================
第一步：环境准备
========================================

1. 确认已安装 Python 3.8 或更高版本
   打开命令提示符，输入：python --version
   
2. 如果未安装 Python，请访问：
   https://www.python.org/downloads/

========================================
第二步：安装依赖
========================================

方法 1：使用批处理文件（推荐）
  双击 run.bat，会自动安装依赖并启动游戏

方法 2：手动安装
  1. 打开命令提示符
  2. 进入项目目录：cd e:\design\aimlab
  3. 运行：pip install -r requirements.txt

========================================
第三步：运行游戏
========================================

方法 1：双击 run.bat

方法 2：命令行
  python main.py

方法 3：直接运行 Python 文件
  右键 main.py -> 打开方式 -> Python

========================================
第四步：游戏操作
========================================

主菜单：
- 按 SPACE 开始游戏
- 按 ESC 退出游戏

游戏中：
- 移动鼠标：控制准星
- 鼠标左键：射击
- 击中靶子：得分
- 未击中：扣分并减少生命值

靶子类型：
🔴 红色普通靶：静止，100 分
🟢 绿色闪现靶：0.5 秒后消失，150 分
🔵 蓝色追踪靶：移动中，200 分

游戏结束：
- 显示最终得分、命中率、TTK 等数据
- 自动生成 Word 分析报告
- 按 SPACE 返回主菜单

========================================
第五步：查看报告
========================================

游戏结束后，报告会自动保存到：
e:\design\aimlab\reports\

报告包含：
- 玩家信息和训练概要
- 详细数据表格
- 火力分布热力图
- 反应时间折线图
- 命中率饼图
- 个性化分析建议

用 Word 打开 .docx 文件即可查看！

========================================
常见问题解答
========================================

Q1: 游戏窗口太大/太小
A: 编辑 config.py，修改 SCREEN_WIDTH 和 SCREEN_HEIGHT

Q2: 游戏太难/太简单
A: 编辑 config.py，修改：
   - TARGET_SPAWN_RATE（靶子生成速度）
   - INITIAL_LIVES（初始生命值）
   - GAME_DURATION（游戏时长）

Q3: 报告生成失败
A: 确保 reports 目录存在，检查是否有写入权限

Q4: 图表中文乱码
A: 这是正常现象，Matplotlib 默认使用英文。
   如需中文，需配置中文字体。

Q5: 游戏卡顿
A: 尝试降低 SCREEN_WIDTH 和 SCREEN_HEIGHT

========================================
测试功能
========================================

测试 1：导入测试
  python test_imports.py
  检查所有模块是否可以正常导入

测试 2：完整功能测试
  python test_full.py
  测试所有核心功能（无需启动图形界面）

========================================
打包提交
========================================

完成游戏后，运行打包脚本：
  python package.py

会自动创建提交包，包含：
- 源代码
- 生成的报告
- 说明文档

然后：
1. 将研修报告 PDF 复制到包目录
2. 将工作照片复制到 照片/ 目录
3. 将演示视频复制到 视频/ 目录
4. 压缩为 ZIP 文件
5. 发送到指定邮箱
