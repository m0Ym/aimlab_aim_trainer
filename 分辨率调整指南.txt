========================================
分辨率和靶子尺寸调整指南
========================================

如果你遇到靶子尺寸不合适或显示问题，请按以下步骤调整：

========================================
问题诊断
========================================

常见问题：
1. 靶子太小，看不清
2. 靶子太大，屏幕上放不下
3. 游戏窗口超出屏幕
4. 准星和靶子比例不协调

========================================
解决方案 1：调整屏幕分辨率
========================================

打开 config.py，找到：

# 屏幕设置
SCREEN_WIDTH = 1920
SCREEN_HEIGHT = 1080

根据你的显示器分辨率修改：

【1366x768 笔记本屏幕】
SCREEN_WIDTH = 1366
SCREEN_HEIGHT = 768

【1600x900 笔记本屏幕】
SCREEN_WIDTH = 1600
SCREEN_HEIGHT = 900

【1920x1080 标准屏幕】
SCREEN_WIDTH = 1920
SCREEN_HEIGHT = 1080

【2K 屏幕 (2560x1440)】
SCREEN_WIDTH = 2560
SCREEN_HEIGHT = 1440

【4K 屏幕 (3840x2160)】
SCREEN_WIDTH = 3840
SCREEN_HEIGHT = 2160

========================================
解决方案 2：调整靶子尺寸
========================================

打开 config.py，找到：

# 靶子尺寸设置
TARGET_RADIUS_MIN = 30
TARGET_RADIUS_MAX = 50

【小靶子（适合高手）】
TARGET_RADIUS_MIN = 20
TARGET_RADIUS_MAX = 35

【中等靶子（标准）】
TARGET_RADIUS_MIN = 30
TARGET_RADIUS_MAX = 50

【大靶子（适合新手）】
TARGET_RADIUS_MIN = 40
TARGET_RADIUS_MAX = 60

【超大靶子（练习用）】
TARGET_RADIUS_MIN = 50
TARGET_RADIUS_MAX = 80

========================================
解决方案 3：窗口模式
========================================

如果想用窗口模式运行：

1. 打开 config.py
2. 修改：

SCREEN_WIDTH = 1280
SCREEN_HEIGHT = 720

3. 打开 game_manager.py
4. 找到第 28 行附近：
   self.screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT))

5. 修改为：
   self.screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT), pygame.RESIZABLE)

这样就可以调整窗口大小了！

========================================
快速测试
========================================

修改配置后：

1. 保存 config.py
2. 重新运行游戏：python main.py
3. 观察靶子尺寸是否合适
4. 如果不合适，继续微调

========================================
准星尺寸调整
========================================

如果准星也需要调整：

1. 打开 crosshair.py
2. 找到第 12 行：
   self.size = 20

3. 修改为合适的值：
   - 小准星：15
   - 标准准星：20
   - 大准星：25-30

========================================
调试技巧
========================================

1. 在游戏界面左上角会显示：
   Targets: X/4
   
   确保这个数字正常显示

2. 如果靶子生成在屏幕外：
   - 检查 SCREEN_WIDTH 和 SCREEN_HEIGHT
   - 确保 TARGET_RADIUS 不会太大

3. 如果靶子重叠严重：
   - 减少 TARGET_RADIUS_MAX
   - 或增加屏幕分辨率

========================================
常见问题
========================================

Q: 靶子太小看不清
A: 增大 TARGET_RADIUS_MIN 和 TARGET_RADIUS_MAX

Q: 靶子超出屏幕
A: 减小 TARGET_RADIUS_MAX，或增大屏幕分辨率

Q: 游戏窗口太大
A: 减小 SCREEN_WIDTH 和 SCREEN_HEIGHT

Q: 准星太小
A: 在 crosshair.py 中增大 self.size

========================================
最佳实践
========================================

1. 先设置正确的屏幕分辨率
2. 再调整靶子尺寸到舒适大小
3. 最后微调准星尺寸
4. 保存配置，开始训练
