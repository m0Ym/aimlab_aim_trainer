========================================
📊 技术实现
========================================

【粒子系统】(particles.py)
- Particle 类：单个粒子
  - 位置、颜色、速度、生命周期
  - 透明度渐变
  - BLEND_RGBA_ADD 发光混合
- ParticleSystem 类：粒子管理器
  - emit()：发射粒子
  - emit_explosion()：爆炸效果
  - emit_trail()：拖尾效果
  - update()：更新所有粒子
  - draw()：绘制所有粒子

【浮动文字】(particles.py)
- FloatingText 类
  - 位置、文字、颜色、字体
  - 向上飘动动画
  - 透明度渐变
  - 缩放效果

【现代化 UI】(game_manager_modern.py)
- draw_gradient_background()：渐变背景
- draw_dynamic_grid()：动态网格
- draw_modern_ui()：现代 HUD
- draw_menu()：主菜单（带粒子）
- draw_game()：游戏界面
- draw_game_over()：结算界面

【连击系统】
- combo：当前连击数
- max_combo：最大连击数
- combo_timer：连击计时器
- COMBO_TIMEOUT：2000ms 超时

【Hit Marker 系统】
- HitMarker 类
  - 白色 X 形（8px 或 10px）
  - 200ms 渐隐
  - 爆头金色圆圈
  - BLEND_RGBA_ADD 混合

🏆 评级系统
========================================

【计算公式】
time_score = 10000 / elapsed_time
accuracy_score = accuracy * 100
combo_bonus = max_combo * 10
total_score = time_score + accuracy_score + combo_bonus

【评级标准】
S+ ≥ 15000  - LEGENDARY（传奇大师）
S  ≥ 12000  - GRANDMASTER（宗师）
A+ ≥ 9000   - MASTER（大师）
A  ≥ 7000   - DIAMOND（钻石）
B+ ≥ 5000   - PLATINUM（白金）
B  ≥ 3500   - GOLD（黄金）
C+ ≥ 2000   - SILVER（白银）
C  ≥ 1000   - BRONZE（青铜）
D  ≥ 500    - IRON（黑铁）
F  < 500    - UNRANKED（未评级）

🎮 操作说明
========================================

【基本操作】
- 移动鼠标：控制准星
- 鼠标左键：射击
- SPACE：开始游戏/重新开始
- C 键：切换准星风格
- ESC：退出游戏

【游戏技巧】
1. 保持连击：2 秒内连续命中
2. 优先爆头：金色特效 + 高分
3. 快速清靶：时间是最重要的因素
4. 准确第一：命中率影响评级

【准星选择】
- 经典绿：传统 FPS 风格
- 青色：高对比度
- 红色：醒目
- 白色：简洁
- 黄色：明亮
- 粉色：电竞风
- 金色：专业感

========================================
🎯 设计理念
========================================

【参考来源】
1. Valorant：极简几何 + 红色高光
2. CS2：深色背景 + 蓝色科技光效
3. Osu：节奏感 + 连击特效
4. Aim Lab：现代渐变 + 动态粒子

【设计原则】
1. 极简主义：去除多余元素
2. 高对比度：确保清晰可见
3. 动态反馈：即时视觉反馈
4. 科技感：未来主义美学
5. 专业感：电竞级标准

【用户体验】
1. 视觉舒适：深邃背景不刺眼
2. 信息清晰：UI 整齐易读
3. 反馈即时：Hit Marker + 粒子
4. 成就感：连击 + 评级系统
5. 流畅动画：60FPS 丝滑体验
