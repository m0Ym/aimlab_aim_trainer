📊 8 种准星预览
========================================

1. 🎯 Crosshair (传统)
   - 十字线 + 外圆环 + 中心点
   - 绿色外圈 + 红色中心
   - 推荐新手使用

   - 小圆点，无其他装饰
   - 绿色，4 像素
   - 职业选手最爱

   - 经典十字形，中心留空
   - 绿色，25 像素
   - 传统 FPS 玩家

4. ⭕ Circle (圆形)
   - 简洁圆环 + 中心红点
   - 黄色外圈 + 红色中心
   - 喜欢圆润手感

5. T T-Shape (T 字)
   - T 字造型，独特风格
   - 青色，20 像素
   - 追求个性

6. ◼️ Square (方形)
   - 方形外框 + 中心点
   - 紫色外圈 + 青色中心
   - 喜欢方正造型

7. 🔶 Diamond (菱形)
   - 菱形外框 + 中心红点
   - 白色外圈 + 红色中心
   - 独特造型

8. 🔺 Triangle (三角)
   - 三角外框 + 中心蓝点
   - 橙色外圈 + 蓝色中心
   - 与众不同

========================================
💡 准星参数
========================================

每种准星都有独立配置：

size: 准星大小
- 点状：4 像素
- 十字：25 像素
- 其他：15-20 像素

thickness: 线条粗细
- 细线：2 像素
- 粗线：3 像素

gap: 中心间隔
- 无间隔：0
- 小间隔：3
- 大间隔：5

color: 外圈颜色
- 绿色：(0, 255, 0)
- 黄色：(255, 255, 0)
- 青色：(0, 255, 255)
- 紫色：(255, 0, 255)
- 白色：(255, 255, 255)
- 橙色：(255, 165, 0)

inner_color: 中心点颜色
- 红色：(255, 0, 0)
- 黑色：(0, 0, 0)
- 白色：(255, 255, 255)
- 青色：(0, 255, 255)
- 蓝色：(0, 0, 255)

========================================
🎨 预设配置
========================================

代码中内置 8 个预设：

```python
presets = {
    'default': {...},    # 传统准星
    'dot': {...},        # 点状准星
    'cross': {...},      # 十字准星
    'circle': {...},     # 圆形准星
    't_shape': {...},    # T 字准星
    'square': {...},     # 方形准星
    'diamond': {...},    # 菱形准星
    'triangle': {...}    # 三角准星
}
```

每个预设包含：
- style: 准星风格
- size: 大小
- thickness: 粗细
- gap: 间隔
- color: 外圈颜色
- inner_color: 中心颜色

========================================
🔧 技术实现
========================================

【CrosshairStyle 枚举】
定义 8 种准星风格的常量

【Crosshair 类】
主要方法：
- __init__(): 初始化
- load_preset(): 加载预设
- set_style(): 设置风格
- next_style(): 切换到下一个
- prev_style(): 切换到上一个
- update(): 更新位置
- draw(): 绘制准星
- get_style_name(): 获取名称

【绘制方法】
- _draw_dot(): 点状
- _draw_cross(): 十字
- _draw_circle(): 圆形
- _draw_crosshair(): 传统
- _draw_t_shape(): T 字
- _draw_square(): 方形
- _draw_diamond(): 菱形
- _draw_triangle(): 三角

【切换逻辑】
```python
def next_style(self):
    self.style = (self.style + 1) % 8
```
按 C 键 → style + 1 → 超过 7 则归零 → 循环
