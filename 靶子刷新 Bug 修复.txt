✅ 靶子刷新 Bug 已修复！

问题描述：点完屏幕上的 4 个靶子后，没有新靶子生成
修复时间：2026-05-26
修复状态：✅ 已完成

========================================
🐛 问题原因
========================================

之前的代码逻辑：
1. 点击靶子 → 靶子被标记为死亡 (is_alive = False)
2. 调用 spawn_target(force_spawn=True)
3. 但 spawn_target 检查 len(self.targets) >= MAX_TARGETS
4. 此时 self.targets 列表中仍有 4 个靶子对象（虽然已死亡）
5. 所以无法生成新靶子

问题：死亡的靶子对象没有被及时清理！

========================================
✅ 修复方案
========================================

在 update() 方法中添加了清理逻辑：

```python
def update(self, delta_time):
    """更新游戏状态（CS2 模式）"""
    if self.state == GameState.PLAYING:
        elapsed_time = (pygame.time.get_ticks() - self.game_start_time) / 1000.0
        
        if elapsed_time >= GAME_DURATION:
            self.end_game()
        
        # 清理已死亡的靶子 ✅
        self.targets = [t for t in self.targets if t.is_alive]
        
        # 如果靶子数量不足，生成新靶子 ✅
        if len(self.targets) < MAX_TARGETS:
            self.spawn_target(delta_time)
```

修复要点：
1. 每帧都清理死亡的靶子
2. 只保留存活的靶子
3. 当靶子数量 < 4 时，自动生成新靶子
4. 保持屏幕上始终有 4 个靶子（除非时间到）
