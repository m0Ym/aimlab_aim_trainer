========================================
🔧 分辨率 Bug 快速修复
========================================

问题：靶子尺寸或屏幕分辨率不合适

✅ 已完成的修复：
========================================

1. 在 config.py 中添加了靶子尺寸配置
   - TARGET_RADIUS_MIN = 30（最小半径）
   - TARGET_RADIUS_MAX = 50（最大半径）

2. 在 game_manager.py 中使用了新的配置
   - 所有靶子尺寸现在从配置读取
   - 自动适配不同屏幕大小

3. 创建了调整指南
   - 查看：分辨率调整指南.txt

========================================
🚀 快速修复步骤
========================================

【方法 1：调整分辨率】

1. 打开 config.py
2. 找到第 8-9 行：
   SCREEN_WIDTH = 1920
   SCREEN_HEIGHT = 1080

3. 根据你的屏幕修改：
   
   笔记本 (1366x768):
   SCREEN_WIDTH = 1366
   SCREEN_HEIGHT = 768
   
   笔记本 (1600x900):
   SCREEN_WIDTH = 1600
   SCREEN_HEIGHT = 900
   
   台式机 (1920x1080):
   保持不变即可

【方法 2：调整靶子大小】

1. 打开 config.py
2. 找到第 42-43 行：
   TARGET_RADIUS_MIN = 30
   TARGET_RADIUS_MAX = 50

3. 根据需要调整：
   
   靶子太小：
   TARGET_RADIUS_MIN = 40
   TARGET_RADIUS_MAX = 60
   
   靶子太大：
   TARGET_RADIUS_MIN = 20
   TARGET_RADIUS_MAX = 35

【方法 3：使用窗口模式】

1. 打开 config.py
2. 修改：
   SCREEN_WIDTH = 1280
   SCREEN_HEIGHT = 720

3. 打开 game_manager.py
4. 找到第 28 行附近
5. 修改为：
   self.screen = pygame.display.set_mode((SCREEN_WIDTH, SCREEN_HEIGHT), pygame.RESIZABLE)

========================================
🔍 常见问题诊断
========================================

问题 1：靶子太小
解决：增大 TARGET_RADIUS_MIN 和 TARGET_RADIUS_MAX

问题 2：靶子超出屏幕
解决：减小 TARGET_RADIUS_MAX 或增大 SCREEN_WIDTH/HEIGHT

问题 3：游戏窗口太大
解决：减小 SCREEN_WIDTH 和 SCREEN_HEIGHT

问题 4：靶子生成在屏幕外
解决：确保 TARGET_RADIUS 不会太大（不超过屏幕的 1/10）
