🎯 操作说明
========================================

【菜单界面】
- ← / → 键：切换地图
- SPACE 键：开始游戏
- C 键：切换准星
- ESC 键：退出游戏

【游戏界面】
- 鼠标移动：控制准星
- 鼠标左键：射击
- ESC 键：退出游戏

========================================
💻 技术实现
========================================

【地图配置模块】(maps.py)
- MapTheme 枚举：定义地图主题
- MapConfig 类：存储地图配置
- get_map_config()：获取地图配置
- get_all_maps()：获取所有地图
- get_map_by_index()：通过索引获取地图

【地图切换系统】
- current_map_index：当前地图索引
- current_map：当前地图配置
- next_map()：切换到下一张地图
- prev_map()：切换到上一张地图
- update_map_colors()：更新颜色配置

【动态颜色系统】
所有颜色都从地图配置中读取：
- bg_gradient_start/end：背景渐变
- grid_color：网格颜色
- grid_secondary：次要网格
- accent_color：强调色
- target_colors：靶子颜色
- particle_color：粒子颜色
- ui_gradient_start/end：UI 渐变

========================================
 扩展地图
========================================

添加新地图只需在 maps.py 中添加：

NEW_MAP = {
    'name': 'New Map Name',
    'theme': MapTheme.NEW,
    'bg_gradient_start': (R, G, B),
    'bg_gradient_end': (R, G, B),
    'grid_color': (R, G, B),
    'grid_secondary': (R, G, B),
    'accent_color': (R, G, B),
    'target_colors': {
        'normal': (R, G, B),
        'flick': (R, G, B),
        'tracking': (R, G, B),
        'headshot': (R, G, B)
    },
    'particle_color': (R, G, B),
    'ui_gradient_start': (R, G, B),
    'ui_gradient_end': (R, G, B),
    'description': 'Map description'
}

然后在 get_all_maps() 中添加即可！
