========================================
✨ 功能介绍
========================================

类似 CS2 5E 平台的准星系统，支持 8 种准星风格：

1. 🎯 传统准星 (Crosshair) - 十字 + 圆环
2. ⚡ 点状准星 (Dot) - 简洁小圆点
3. ➕ 十字准星 (Cross) - 经典十字形
4. ⭕ 圆形准星 (Circle) - 简洁圆环
5. T 字形准星 (T-Shape) - T 字造型
6. ◼️ 方形准星 (Square) - 方形外框
7. 🔶 菱形准星 (Diamond) - 菱形造型
8. 🔺 三角形准星 (Triangle) - 三角造型

========================================
🎮 使用方法
========================================

【方法 1：游戏中切换】
1. 开始游戏后
2. 按 C 键切换准星风格
3. 每按一次切换到下一种
4. 左上角显示当前准星名称

【方法 2：菜单预览】
1. 在主菜单界面
2. 显示当前准星风格名称
3. 按 C 键预览不同准星
4. 选择喜欢的风格后开始游戏

========================================
📊 8 种准星详解
========================================

【1. 传统准星 (Crosshair)】🎯
特点：十字线 + 外圆环 + 中心点
颜色：绿色外圈 + 红色中心
大小：20 像素
适用：全面型选手，推荐新手使用

【2. 点状准星 (Dot)】⚡
特点：小圆点，无其他装饰
颜色：绿色
大小：4 像素
适用：精准定位，CS 职业选手最爱

【3. 十字准星 (Cross)】➕
特点：经典十字形，中心留空
颜色：绿色
大小：25 像素
适用：传统 FPS 玩家，穿越火线老玩家

【4. 圆形准星 (Circle)】⭕
特点：简洁圆环 + 中心红点
颜色：黄色外圈 + 红色中心
大小：15 像素
适用：喜欢圆润手感的玩家

【5. T 字形准星 (T-Shape)】T
特点：T 字造型，独特风格
颜色：青色
大小：20 像素
适用：追求个性的玩家

【6. 方形准星 (Square)】◼️
特点：方形外框 + 中心点
颜色：紫色外圈 + 青色中心
大小：15 像素
适用：喜欢方正准星的玩家

【7. 菱形准星 (Diamond)】🔶
特点：菱形外框 + 中心红点
颜色：白色外圈 + 红色中心
大小：18 像素
适用：喜欢独特造型的玩家

【8. 三角形准星 (Triangle)】🔺
特点：三角外框 + 中心蓝点
颜色：橙色外圈 + 蓝色中心
大小：20 像素
适用：追求与众不同的玩家

========================================
🎨 准星参数
========================================

每种准星都有以下可调参数：

- size: 准星大小 (15-25 像素)
- thickness: 线条粗细 (2-3 像素)
- gap: 中心间隔 (0-5 像素)
- color: 外圈颜色 (RGB)
- inner_color: 中心点颜色 (RGB)

========================================
💡 推荐配置
========================================

【新手推荐】
传统准星 (Crosshair)
- 有参考线，容易瞄准
- 中心点明显，定位准确

【进阶推荐】
点状准星 (Dot)
- 简洁不挡视野
- 职业选手首选

【精准推荐】
十字准星 (Cross)
- 经典造型
- 横竖线辅助瞄准

【个性推荐】
圆形准星 (Circle) 或 菱形准星 (Diamond)
- 独特造型
- 不易与其他游戏混淆

========================================
🔧 自定义准星
========================================

如果想自定义准星参数：

1. 打开 crosshair.py
2. 找到 presets 字典（第 46-111 行）
3. 修改现有预设或添加新预设

示例：创建自定义准星
```python
'custom': {
    'style': CrosshairStyle.CROSS,
    'size': 30,
    'thickness': 4,
    'gap': 8,
    'color': (255, 0, 0),  # 红色
    'inner_color': (0, 0, 0)  # 黑色中心
}
```

========================================
⚙️ 技术细节
========================================

实现方式：
- CrosshairStyle 枚举：定义 8 种风格
- Crosshair 类：支持切换和绘制
- presets 字典：存储预设配置
- next_style() 方法：循环切换
- get_style_name() 方法：显示名称

切换逻辑：
按 C 键 → next_style() → style = (style + 1) % 8 → 循环切换
