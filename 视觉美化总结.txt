# 5 层结构
1. 暗色外发光 (10, 10, 10) - 阴影层

【2. Hit Marker 动画】
```python
# 透明度渐变
alpha = 255 - int((elapsed / 200) * 255)
# BLEND_RGBA_ADD 混合模式
screen.blit(surface, pos, special_flags=pygame.BLEND_RGBA_ADD)
```

【3. 磨砂玻璃面板】
```python
# 支持透明度的 Surface
panel = pygame.Surface((SCREEN_WIDTH, 50), pygame.SRCALPHA)
panel.fill((15, 18, 20, 180))  # Alpha=180
```

【4. 全息网格】
```python
# 80px 网格
for x in range(0, SCREEN_WIDTH, 80):
    pygame.draw.line(screen, GRID_COLOR, (x, 0), (x, SCREEN_HEIGHT), 1)
```
