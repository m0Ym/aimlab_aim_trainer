Aim Lab 练枪模拟器 - AI 使用说明
=====================================

本文档记录了在开发过程中如何使用 AI 辅助编程，包括 Prompt 构思、AI 建议和代码修改过程。

一、项目架构设计阶段
-------------------

1. Prompt 构思：
"我需要开发一个类似 Aim Lab 的练枪模拟器，使用 Pygame 框架。要求包含以下功能：
- 自定义准星系统
- 多种类型的目标靶子（普通靶、闪现靶、追踪靶）
- 数据追踪和分析系统
- 自动生成 Word 报告
请帮我设计一个面向对象的架构，包含主要的类和方法。"

2. AI 建议：
- 采用面向对象设计，使用继承和多态
- 分离游戏逻辑、数据分析和报告生成
- 使用状态机管理游戏状态

3. 修改过程：
- 根据课程要求调整了类的职责划分
- 增加了 DataTracker 类专门负责数据记录
- 添加了 Config 文件统一管理配置参数


二、多态实现阶段
----------------

1. Prompt 构思：
"我需要实现三种靶子类型：
- Target 基类：包含基本的绘制和点击检测
- FlickTarget：0.5 秒后自动消失
- TrackingTarget：按正弦波移动
请使用 Python 的继承和多态机制实现。"

2. AI 建议的代码：
- 使用 super() 调用父类方法
- 重写 update() 方法实现不同行为
- 使用勾股定理进行碰撞检测

3. 修改过程：
- 调整了 FlickTarget 的透明度渐变效果
- 优化了 TrackingTarget 的运动轨迹算法
- 增加了 HeadshotTarget 作为额外挑战


三、数据分析阶段
----------------

1. Prompt 构思：
"我有以下游戏数据：点击时间戳、鼠标坐标、目标坐标、是否命中。
请使用 Pandas 计算：
- 平均击杀时间 (TTK)
- 命中率
- 平均偏移距离"

2. AI 建议的代码：
```python
import pandas as pd
import numpy as np

def calculate_ttk(hit_times):
    ttk_values = [hit_times[i] - hit_times[i-1] for i in range(1, len(hit_times))]
    return np.mean(ttk_values) * 1000  # 转换为毫秒
```

3. 修改过程：
- 增加了边界条件处理（空数据情况）
- 优化了偏移距离的计算逻辑
- 添加了反应时间序列的提取方法


四、可视化阶段
-------------

1. Prompt 构思：
"请使用 Matplotlib 绘制：
- 火力分布热力图（未命中点的散点图）
- 反应时间折线图
要求美观专业，适合放入报告。"

2. AI 建议：
- 使用 scatter 绘制散点图，按时间着色
- 使用 plot 绘制折线图，添加平均值参考线
- 设置合适的 figure size 和 dpi

3. 修改过程：
- 调整了颜色映射方案（使用 Reds）
- 增加了中文标题支持
- 优化了图表布局和边距


五、Word 报告生成阶段
-------------------

1. Prompt 构思：
"请使用 python-docx 创建一个专业的 Word 报告，包含：
- 标题和玩家信息
- 数据表格
- 插入生成的图表
- 分析建议
要求格式规范，适合打印。"

2. AI 建议的关键点：
- 设置合适的页面边距（2.5cm）
- 使用标题层级（Heading 0, 1, 2）
- 表格使用 Table Grid 样式
- 图片添加居中标题

3. 修改过程：
- 增加了异常处理（图片加载失败）
- 优化了字体大小和样式
- 添加了个性化的分析建议


六、调试优化阶段
---------------

1. 遇到的问题：
- 靶子生成在屏幕外
- 数据越界错误
- 图表保存路径错误

2. AI 辅助 Debug：
Prompt: "我的靶子有时生成在屏幕外，导致看不到。生成代码是：
x = random.randint(0, SCREEN_WIDTH)
y = random.randint(0, SCREEN_HEIGHT)
请帮我修复。"

AI 建议：
```python
x = random.randint(radius, SCREEN_WIDTH - radius)
y = random.randint(radius, SCREEN_HEIGHT - radius)
```

3. 解决方案：
- 在生成靶子时考虑半径边界
- 在计算前检查数据是否为空
- 使用绝对路径保存文件


七、使用心得
-----------

1. AI 的优势：
- 快速生成样板代码
- 提供多种实现方案
- 帮助理解复杂概念

2. 需要注意：
- AI 生成的代码需要仔细审查
- 边界条件和异常处理需要手动补充
- 业务逻辑需要结合具体需求调整

3. 最佳实践：
- 提供详细的上下文信息
- 分步骤询问复杂问题
- 对 AI 代码进行测试和验证
