========================================
🔧 C 键切换准星 - 使用说明
========================================

如果你发现按 C 键没反应，请检查以下几点：

========================================
✅ 正确的使用方法
========================================

【方法 1：在主菜单切换】
1. 运行游戏：python main.py
2. 看到主菜单界面
3. 按 C 键切换准星
4. 屏幕中央会显示"当前准星：XXX"
5. 控制台会打印"切换到准星：XXX"

【方法 2：在游戏中切换】
1. 按 SPACE 开始游戏
2. 游戏进行中按 C 键
3. 左上角会显示"Crosshair: XXX"
4. 控制台会打印"切换到准星：XXX"

========================================
📍 准星显示位置
========================================

【主菜单】
- 中央显示：当前准星：Crosshair (传统)
- 下方显示：按 C 键切换准星风格

【游戏中】
- 左上角显示：Crosshair: Crosshair (传统)
- 位置：在 Targets 显示下方

========================================
🎯 8 种准星循环顺序
========================================

按 C 键切换顺序：
1. Crosshair (传统) → 
2. Dot (点状) → 
3. Cross (十字) → 
4. Circle (圆形) → 
5. T-Shape (T 字) → 
6. Square (方形) → 
7. Diamond (菱形) → 
8. Triangle (三角) → 
9. 回到 Crosshair (传统) ...循环

========================================
🔍 调试方法
========================================

【查看控制台输出】
按 C 键后，控制台应该会显示：
切换到准星：Dot (点状)
切换到准星：Cross (十字)
...

如果控制台没有输出，说明 C 键没有被识别

【可能的问题】
1. 键盘驱动问题
   - 尝试重启游戏
   - 检查键盘是否正常

2. 窗口焦点问题
   - 确保游戏窗口是当前活动窗口
   - 点击游戏窗口获得焦点

3. 按键冲突
   - 确保没有其他程序占用 C 键
   - 关闭可能冲突的软件

========================================
⚠️ 常见问题
========================================

Q: 按 C 键没反应
A: 
1. 确保游戏窗口有焦点（点击窗口）
2. 查看控制台是否有输出
3. 检查键盘是否正常
4. 重启游戏试试

Q: 准星名称变了，但形状没变
A: 
1. 这是正常的，某些准星差异不明显
2. 多按几次 C 键，观察明显变化
3. 点状和十字形差异最明显

Q: 控制台没有输出
A: 
1. 可能是代码问题，检查 game_manager.py 第 70 行
2. 确保有这行代码：print(f"切换到准星：{self.crosshair.get_style_name()}")
3. 重新运行游戏

========================================
📝 代码位置
========================================

如果 C 键真的没反应，检查这个文件：

game_manager.py 第 70-71 行：
```python
if event.key == pygame.K_c:  # 按 C 键切换准星（任何状态都可以）
    self.crosshair.next_style()
    print(f"切换到准星：{self.crosshair.get_style_name()}")
```

确保这段代码存在！
